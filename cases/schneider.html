施耐德电气上海物流中心 × 极智嘉

施耐德电气上海仓库，正式称“施耐德电气上海物流中心”，简称DCSH。它是服务施耐德电气产品仓储、订单履约和配送的企业物流中心，也是其自动化、数字化技术的应用现场。极智嘉机械臂拣选站是在这里开展的技术试点。

下面把目前能查到的公开信息集中整理。不同年份的数据分别注明，避免把历史规模当作当前规模。

二、主要做什么物流业务

它主要服务施耐德电气自身的产品供应链。公开资料显示，涉及接触器、断路器、继电器等电气产品；历史报道还提到大件UPS产品的存储区域。施耐德官方参访介绍、2019年现场报道。

业务可以理解为：

接收货物 → 入库和存储 → 根据订单组织拣货 → 复核、包装 → 发运配送。

六、WMS及软件系统：知道什么、不知道什么

能够确认的是：

  • 仓库有订单、库存、物流作业与自动化协同需求。
  • 现场应用了施耐德的数字化与自动化技术。
  • 极智嘉工作站与既有流程完成集成。

目前没有可靠公开资料明确给出该仓库当前WMS的名称、供应商、版本，以及机械臂站的完整接口关系。

因此，下面只能作为理解用的典型结构，不能写成现场已核实架构：

订单／库存系统 → 仓库作业协调软件 → 搬运及拣选设备 → 执行结果反馈 → 更新订单和库存。

同样，不能仅因为设备位于施耐德仓库，就认定机械臂站使用施耐德PLC，或所有机器人都来自极智嘉。

九、对你项目最有价值的调研点

这个案例的价值在于：**工业品B2B仓库中，机械臂如何融入已有物流系统。**现场重点应看：

  1. 供料与换箱：库存箱由什么设备送来，谁确认到位，谁安排回库。
  2. 商品边界：实际抓哪些商品，尺寸重量、纸盒、裸件及特殊包装的限制。
  3. 扫码与放置：条码读不到、抓多件、掉件、目标箱满了如何处理。
  4. 软件闭环：WMS对接谁，任务完成由谁确认，失败是否回传。
  5. 真实产能：包含等待、换箱和异常后，每小时实际完成多少件。
  6. 人工介入：一班需要介入几次，哪些异常必须由人处理。
  7. 商业情况：试点还是正式采购，验收标准是什么，是否准备复制到其他仓库。

**目前仍未公开的关键资料包括：完整设备清单、WMS品牌、工作站数量、实际SKU测试清单、持续运行日志、采购价格及投资回报。**这些是下一步向施耐德或极智嘉核实最有价值的内容。

数据补充与口径说明

属于“拣选（Picking）”，不是S系列那类“分拣（Sorting）”。但公开案例还不足以确认，施耐德现场采用的是“直接按订单拣选”，还是“批量拣选／合箱理货”。

需要分两个层次看：

判断层次 结论
设备类别 已明确是 Robot Arm Picking Station机械臂拣选工作站：从库存箱中抓取商品
具体业务模式 是否直接放入订单箱、先批量提总，或合并库存箱，施耐德案例未充分披露

区分依据是商品去向：

  • 库存箱 → 对应订单箱：订单拣选。
  • 库存箱 → 批量容器，之后再按订单分开：批量拣选＋后续分拣。
  • 多个库存箱 → 合并库存箱：合箱理货。
  • 已取出的商品／包裹 → 各订单或目的地格口：分拣。

“仓储商品拣选自动化——机械臂单件拣选；具体订单组织模式待确认。”

我前面直接把施耐德现场归为订单拣选，表述过于具体，应以上述分类为准。
