hummel A/S × Element Logic／RightHand Robotics

hummel A/S 的拣选项目

项目与作业信息

  • **地点：**hummel Distribution Center（hDC），丹麦帕德堡（Padborg）。中心服务电商、批发和零售客户。hummel 招聘页
  • 拣选方案：在原有 AutoStore 上集成 Element Logic 的 eOperator，采用 RightHand Robotics 的 AI 拣选技术，处理单件商品拣选。Element Logic，2025-11-13
  • **商品与订单：**运动服饰及相关商品；自动化方案面向多种 SKU 和包装类型，适应季节性和高峰订单。Element Logic 项目介绍
  • **上线过程：**Element Logic 称 eOperator 与 AutoStore 的集成在数天内完成；hummel 表示曾测试当地另一家供应商的方案，之后选择 Element Logic。Element Logic，2025-11-13
  • **作业目标与效果：**减少人工触碰，提高拣选速度、稳定性和可靠性。供应商和 hummel 公开称效果有所改善，但没有在该案例中给出改造前后的百分比或订单行/小时数据。Element Logic 项目介绍
